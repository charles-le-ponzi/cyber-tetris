# TETRA//Y2K

A cyber-Y2K themed Tetris in a single self-contained HTML file. No dependencies, no build step.

- Full SRS rotation with wall kicks, 7-bag randomizer, hold, ghost piece
- DAS/ARR auto-shift, soft/hard drop, lock delay with move resets
- Combos, back-to-back Tetris bonus, level speed curve, high score persistence
- Procedural eurobeat/trance soundtrack synthesized live with WebAudio (no audio files)
- Liquid-chrome panels, neon glow, animated grid floor, particle bursts, screen shake
- Touch controls on mobile, auto-scales to any window size

## Controls

| Key | Action |
|-----|--------|
| ◀ ▶ / A D | Move |
| ▼ / S | Soft drop |
| Space | Hard drop |
| ▲ / X | Rotate CW |
| Z | Rotate CCW |
| C | Hold |
| P | Pause |
| M | Mute |
| Enter | Start |

## Play

Open `index.html` in any modern browser.
